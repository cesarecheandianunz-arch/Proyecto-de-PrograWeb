Las rutas ya están escritas. No hay que editar componentes ni volver a cargar la
misma fotografía en cada pantalla: inventario, catálogo y ficha leen la del equipo.
Los datos de ejemplo guardados anteriormente sin fotos se completan una sola vez,
sin sustituir las fotografías que el usuario ya hubiera agregado.

Usa archivos pequeños, preferentemente de 100 a 300 KB y un encuadre cuadrado para
los equipos. El archivo del almacén puede ser horizontal.

Al faltar un archivo se muestra «Sin fotografía disponible». Después de copiarlo,
recarga la página para volver a intentar mostrarlo.

La fotografía de un daño se selecciona en el formulario de devolución; no necesita
un archivo fijo de ejemplo. No hacen falta fotos de perfil: los avatares usan iniciales.
